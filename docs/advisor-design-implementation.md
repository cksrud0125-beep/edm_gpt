# 유학 GPT 디자인 적용

기준: `edm-design-system.md` (사용자 제공 edm.md 원문).
적용 범위: `#advisor` 유학 GPT 화면. 홈 화면과 추천 데이터/분석 로직은 변경하지 않음.

- §0–2: 흰 배경, Pretendard, 브랜드 그린 #1EC95B, 중립 텍스트, PC/Mobile 타이포그래피. 상담 시작 화면의 일러스트·이모지 제거.
- §3–5: 12/8/6컬럼 기반 카드·선택 그리드, 4px 기반 간격, 카드 12px / 버튼·입력 8px / 칩 pill.
- §6–8: light 보더 카드의 blue shadow, SVG 아이콘, 입력 focus·버튼 disabled, 선택 칩, 카드 이미지 PC 200px/Mobile 160px.
- §8-6: 회색 44px 캐러셀 조작 버튼, 검정 40px plus 버튼. 사용자 요청에 따라 수동 좌우 조작과 전체 추천 유지.
- 기존 공식 썸네일 이미지, 제목 줄바꿈·글자색 유지. PC 26px/Mobile 20px 적용.
- 기록 사이드바와 상담 헤더는 기존 상담 업무 흐름에 맞춘 레이아웃. 홈페이지용 전체 내비게이션·푸터는 추가하지 않음.

검증: 프로덕션 빌드 및 기존 문장 분석/추천 회귀 검증 통과. 브라우저 시각 검증은 수행하지 않음.

## 사용자 리뷰 반영
- 시작 화면 중앙 정렬, 소제목 `edm 맞춤 유학`, 에디 이미지(61×96px) 추가.
- 에디 사용은 후속 사용자 명시 요청으로 디자인 문서의 일러스트 제한보다 우선 적용.
- 사이드바 `나의 유학 메이트`, `맞춤 프로그램 찾기` 삭제. 조건 기록 유지.
